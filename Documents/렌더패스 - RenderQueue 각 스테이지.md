# 렌더패스 - RenderQueue 각 스테이지

`RenderQueue`는 렌더링 순서를 결정하는 정수값입니다. 값이 낮을수록 먼저 렌더링됩니다.

## 스테이지

| 이름 | 값 | 용도 |
| --- | ---: | --- |
| `Background` | `1000` | 배경과 가장 먼저 그려야 하는 오브젝트에 사용합니다. |
| `Geometry` | `2000` | 기본 불투명 메시를 그리는 데 사용합니다. |
| `AlphaTest` | `2450` | 알파 테스트가 필요한 오브젝트에 사용합니다. |
| `Transparent` | `3000` | 알파 블렌딩이 필요한 Sprite와 투명 오브젝트에 사용합니다. |
| `Overlay` | `4000` | 화면 위에 항상 표시해야 하는 UI와 오버레이에 사용합니다. |

## 사용 규칙

기본 Material은 `Geometry`를 사용합니다. 기본 Sprite Material은 `Transparent`를 사용합니다.

각 스테이지 사이의 값은 비워 둡니다. 특정 스테이지 내부의 순서를 조정할 때는 기준값에 작은 오프셋을 더합니다.

```csharp
RenderQueue.Transparent + 10
```

투명 오브젝트는 카메라 거리와 Sort Order를 함께 고려해야 합니다. `RenderQueue`는 큰 단계의 순서를 정하고, 세부 순서는 렌더러의 정렬 정책이 결정합니다.

새로운 렌더 스테이지가 필요할 때는 기존 값과 겹치지 않는 기준값을 추가합니다. 관련 코드와 이 문서의 표를 함께 수정해야 합니다.
