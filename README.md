## Release/Publish 빌드 시
- 게임의 아트 작업물인 `Assets`와 아트 작업물의 바이너리 패키지인 `Data`는 **파일 용량 등의 이유로 Git 저장소에 직접 포함하지 않습니다.**
- Assets 폴더와 Data 폴더를 **[\[이곳\]]()** 에서 다운받아 최상단 폴더에 배치해두고 빌드해주세요.

### Android
- Android 진입점 프로젝트를 빌드하는 경우에는 추가적인 폴더 구성이 필요합니다.
- `YumeArisu.Android` 내부에 `Assets`라는 이름의 **빈 폴더를 생성**한 뒤, `Data` 폴더를 해당 위치에 배치해 주세요.

```text
YumeArisu/
├─ Assets/
├─ Data/
├─ YumeArisu.Android/
│  └─ Assets/
│     └─ Data/
└─ ...
```
